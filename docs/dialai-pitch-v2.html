09 · Core concept DialAI

통화 보조가 아니라 통화 위임

BEFORE
Assistance

AI가 내가 전화하는 과정을 도와준다

ARS와 대기는 줄여도, 상담사 연결 뒤에는 결국 사용자가 통화를 이어갑니다.

DIALAI
Delegation

전화 업무 자체를 AI에게 맡긴다

상담사 연결 뒤에도 AI가 직접 대화하고 업무 완료까지 수행합니다.

저희는 이 차이를 Call Assistance와 Call Delegation이라고 정의했습니다. 기존의 많은 서비스는 전화 과정을 보조합니다. ARS를 보기 쉽게 만들어 주거나, 상담사가 받을 때까지 대신 기다려 주거나, 통화를 요약해 줍니다. 이것도 분명 편리합니다. 하지만 결국 중요한 대화가 시작되면 사용자가 다시 전화에 들어가야 합니다. DialAI는 여기서 한 단계 더 갑니다. 상담원이 연결돼도 사용자가 다시 들어갈 필요가 없습니다. AI가 계속 대화하고, 사용자가 요청한 업무가 끝날 때까지 수행합니다.

AI가 판단할 수 없는 상황에서는 사용자에게 질문을 보내고, 사용자는 버튼이나 채팅으로 답할 수 있습니다. 마지막으로 전화가 끝나면 전체 통화 내용, 핵심 요약, 최종 업무 처리 결과를 제공합니다. 추가적으로 사용자 말투나 Voice Cloning도 적용할 수 있습니다.

개인의 Agent가 기관에 직접 전화해 업무를 끝냅니다.

물론 Voice AI 시장에는 이미 많은 서비스가 있습니다. 기업용 Voice Agent는 AI가 기업 상담원을 대신해 고객을 응대합니다. 에이닷이나 익시오 같은 개인용 AI 서비스도 전화 대기나 대신 받기 같은 기능을 제공합니다. 하지만 저희가 집중한 위치는 조금 다릅니다. 개인 사용자의 Agent가 되어, 제3의 기관에 직접 전화하고, 그 기관의 실제 상담사와 대화해서 사용자의 업무를 완료하는 것입니다. 기업용 AI는 기업을 대신하고, 기존 개인용 AI는 주로 사용자의 전화를 보조합니다. DialAI는 개인 사용자를 대신해 업무를 수행합니다. 그래서 저희가 이야기하는 핵심 포지션은 Call Assistance가 아니라 Call Delegation입니다. [최종안 확인] 경쟁사 기능은 발표 시점 기준으로 다시 검증해야 합니다.

Voice 모델은 앞으로 계속 좋아지고, 결국 많은 회사가 사용할 수 있게 됩니다. 저희가 축적하려는 것은 Institution-specific Task Execution Data, 즉 기관별 전화 업무 실행 데이터입니다. 예를 들어 특정 병원의 예약 변경 전화를 반복해서 처리하면, 어떤 ARS 경로를 타야 하는지, 어떤 환자 정보가 필요한지, 상담사가 보통 어떤 질문을 하는지, 어떤 조건에서는 사용자에게 다시 물어봐야 하는지, 그리고 어떤 이유로 실패하는지가 계속 쌓입니다.

COMPOUNDING ASSET 기관별 업무
실행 데이터
결국 통화량이 늘어날수록 기관별 업무 데이터가 쌓이고, AI의 성공률과 속도가 높아지고, 더 많은 사용자가 들어오면서 다시 더 많은 데이터가 쌓이는 구조를 만들 수 있습니다. 저희는 이를 Data Flywheel이라고 보고 있습니다. 한 문장으로 표현하면, “남들은 AI가 전화를 잘하게 만들고, 우리는 AI가 전화로 일을 끝내는 법을 축적합니다.”
16 · Vision DialAI

모든 AI에게 ‘전화할 수 있는 손’을 붙입니다

NOW

Web App

사용자가 DialAI에 직접 전화 업무를 요청합니다.

NEXT

MCP / Agent Tool

다른 AI가 DialAI를 실행 도구로 호출합니다.

THEN

Any AI → Call

ChatGPT와 Agent가 실제 전화 업무까지 완료합니다.

정보를 알려주는 AI에서, 대신 일을 처리하는 AI로.

그리고 DialAI를 단순히 하나의 웹 서비스로 끝내고 싶지는 않습니다. 처음에는 사용자가 DialAI 웹앱에서 직접 전화 업무를 요청합니다. 하지만 이후에는 MCP나 Agent Tool 형태로 확장할 수 있습니다. 그러면 사용자가 ChatGPT나 다른 AI에게 “다음 주 병원 예약 변경해 줘.”라고 이야기하는 순간, 그 Agent가 DialAI를 호출하고, DialAI가 실제 세상에 전화를 걸어 업무를 처리합니다. 즉 저희가 만들고 싶은 것은 모든 AI에게 현실 세계에 전화를 걸 수 있는 ‘손’을 붙이는 것입니다.
