1순위: Intercom — 전체 UX 베이스

가장 잘 맞음.

Intercom 디자인은 고객지원 제품답게 크림/화이트 배경 + 검정 텍스트 + 카드 중심 + 하나의 강한 포인트 컬러 구조야. 장식보다는 실제 제품 화면과 대화 인터페이스가 중심이라, 너희 서비스의 업무 지시 → 통화 진행 → 질문 → 완료 결과 흐름을 보여주기 좋다.

특히 이런 화면에 적합해.

메인 업무 요청창
AI의 사전 질문
통화 중 채팅/Transcript
[A로 변경] [B로 변경] 같은 사용자 개입 버튼
전화 완료 후 결과 카드

하나만 DESIGN.md 고르라고 하면 Intercom 추천.

2순위: ElevenLabs — Voice 정체성

너희가 전화/음성 AI라는 것을 디자인적으로 보여주는 데 가장 적합해.

ElevenLabs는 오프화이트 기반에 무채색 UI를 쓰면서, 컬러를 마구 쓰는 대신 부드러운 gradient orb / voice 관련 요소를 포인트로 둬. 버튼도 pill 형태라 전체적으로 AI 음성 서비스인데 부담스럽게 기술적으로 보이지 않는다.

너희한테는 여기서

통화 중 waveform
AI speaking indicator
음성 프로필
Voice cloning 화면
통화 시작 버튼
전화 연결 중 animation

정도만 가져오면 좋을 듯.

ElevenLabs 전체를 따라가기보다는 Voice 부분의 비주얼 언어를 가져오는 용도.

3순위: Linear — Agent 실행 상태 UX

Linear는 검은색 기반의 굉장히 정밀하고 밀도 높은 SaaS 디자인이고, 상태·작업·정보 계층을 표현하는 데 강해. 한 가지 라벤더 계열 accent를 제한적으로 사용하는 것도 특징이고.

너희 서비스에서는 디자인 자체보다는 정보 구조를 참고하면 좋겠어.

예를 들면 전화 한 건을:

Preparing
→ Calling
→ Navigating ARS
→ Waiting for agent
→ Talking
→ Waiting for your input
→ Completed

이런 식으로 보여주는 부분.

통화 History도

서울OO병원
진료 일정 변경
Completed · 4m 32s
8/20 → 8/23

처럼 굉장히 간결하게 만드는 데 Linear 느낌이 잘 맞아.

다만 Linear 디자인 전체를 가져오면 개발자용 Agent SaaS처럼 보일 가능성이 있어서 메인 레퍼런스로는 비추천이야.

그래서 내가 한다면 비율은 대충:

Intercom 60% + ElevenLabs 30% + Linear 10%

이렇게 갈 것 같아.

전체적인 비주얼은 Intercom처럼 밝고 신뢰감 있게, 전화가 실제 진행되는 순간에는 ElevenLabs처럼 Voice AI라는 게 느껴지게, Agent의 작업 상태와 History는 Linear처럼 정밀하게.

특히 해커톤이라면 메인 화면을 복잡한 Dashboard로 시작하지 않고,

What should I call about?

서울OO병원에 전화해서 다음 주 진료 일정을 금요일 오후로 변경해줘

Call for me →

이런 큰 Agent command box 하나를 중심으로 시작하는 게 가장 임팩트 있을 것 같아.

그리고 전화가 시작되면 화면 자체가 Live Call Workspace로 전환되는 거지.

왼쪽/중앙에는 실시간 Transcript, 상단에는 서울OO병원 · 02-XXXX-XXXX · 03:42, 오른쪽에는 현재 AI가 수행 중인 작업/사용자 개입 카드. 하단에는 “AI에게 추가 지시하기” 채팅창.

이러면 사용자가 데모를 보는 순간 “아, 얘한테 업무를 말하면 진짜 대신 전화하고 나는 필요할 때만 개입하는 서비스구나”가 바로 전달될 거야.


이 내용 참고해서, 목업 웹페이지 만들어줘 -> 어떤 디자인 적용하는게 좋을지 보는 용도야
-> 필요하면 여러 웹페이지 만들어서 비교해도 되고, 디자인 볼 수 있게 다양한 UI 요소 만들어줘
