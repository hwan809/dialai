# 국내 전화망 확장 조사 메모

작성일: 2026-08-16

## 목적

DialAI가 장기적으로 ClawOps 같은 단일 서비스에 의존하지 않고 국내 전화망을 사용할 수 있는 방법을 조사한다. 아직 결론이나 구현 사양으로 확정된 문서가 아니라 후속 타당성 조사 범위를 기록한 메모다.

## 조사 경로

### 1. SaaS용 국내 전화망

- MakeCall 같은 국내 SIP·전화 API 사업자를 연동하거나 유사한 서비스를 구성할 수 있는지 확인한다.
- 고객에게 국내 070 또는 010 전화번호를 제공·임대·재판매할 수 있는 계약 및 사업 구조를 조사한다.
- 번호 발급, 본인확인, 통신사업자 또는 리셀러 계약, 전기통신사업 관련 신고 의무를 확인한다.
- 외부 SIP, SIP Trunk, 실시간 오디오 스트리밍, 발신 API 및 웹훅 제공 여부를 비교한다.
- 국내 통신 3사 수신 화면에 국내 번호가 정상적으로 표시되는지 확인한다.
- 자동·AI 발신 허용 범위와 스팸 방지, 녹취 고지, 개인정보 처리 요건을 검토한다.

### 2. 개인 SIM을 이용한 로컬 발신 게이트웨이

- 본인 명의 010 SIM과 전화번호를 DialAI 발신에 사용할 수 있는지 확인한다.
- LTE/5G USB 모뎀, SIM 게이트웨이, 안드로이드 단말 중 Mac에서 제어하기 적합한 방식을 비교한다.
- 로컬 장비를 SIP 또는 HTTP API 게이트웨이로 노출해 DialAI 및 OpenAI Realtime과 연결할 수 있는지 검증한다.
- 통화 오디오의 양방향 입출력, DTMF, 통화 상태 이벤트, 동시통화 제한을 확인한다.
- 이동통신사 이용약관상 자동발신, 서버형 사용, SIM 게이트웨이 사용이 허용되는지 확인한다.

## 반드시 구분할 결과

- 개인용 실험 환경에서 기술적으로 가능한가
- 통신사 약관과 법규 안에서 지속적으로 사용할 수 있는가
- DialAI 고객에게 상용 SaaS 기능으로 판매할 수 있는가

개인 SIM으로 한 번 발신되는 것과 010 번호를 SaaS 상품으로 판매할 수 있는 것은 별개의 문제로 취급한다.

## 다음 조사에서 답할 질문

1. 국내 010 번호를 제3자 SaaS 고객에게 제공할 수 있는 계약 형태가 존재하는가?
2. MakeCall 또는 통신사 파트너가 외부 SIP 자격 증명과 국내 발신번호를 함께 제공하는가?
3. 개인 SIM 기반 장비에서 통화 오디오를 실시간 AI에 안정적으로 연결할 수 있는가?
4. 각 방식의 초기 장비비, 월 기본료, 분당 요금, 최소 약정과 동시통화 비용은 얼마인가?
5. MVP, 개인용 기능, 상용 멀티테넌트 서비스에 각각 어떤 전화망 방식을 써야 하는가?
