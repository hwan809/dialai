## 1순위: Claude +

페이지 자체에서 `minimal / professional / corporate / startup`으로 분류돼 있고, 커뮤니티 반응도 높은 편이야. 카드·입력창·채팅·폼처럼 너희 서비스에 필요한 기본 컴포넌트를 무난하게 소화할 수 있어. ([tweakcn][1])

### 잘 맞는 화면

- 첫 화면의 업무 요청 입력창
- 전화 전 AI 질의응답
- 통화 내역 목록
- 전체 통화 Transcript
- 통화 결과 요약 카드
- 설정 및 개인정보 입력 화면

너희 서비스는 병원·공과금·통신사 같은 **신뢰가 중요한 업무**를 다루기 때문에, 너무 사이버펑크스럽거나 실험적인 것보다 이런 차분한 SaaS 스타일이 좋아.

**최종 베이스 테마로 가장 추천.**

## 2순위: Vescrow 1.2

`minimal / startup / soft / futuristic`로 분류된 테마야. 대시보드와 애플리케이션 화면을 함께 보여주기 때문에, **통화가 진행되는 실시간 Agent 화면**에 특히 잘 맞아. ([tweakcn][2])

### 잘 맞는 화면

- `ARS 탐색 중`
- `상담사 연결 대기 중`

- `사용자 답변 대기 중`
- 실시간 통화 시간
- Agent 작업 상태
- 통화 단계 타임라인

다만 전체 서비스를 이 스타일로 만들면 평범한 AI SaaS 대시보드처럼 보일 수 있어.

그래서 **전체 테마보다는 Live Call 화면의 레이아웃과 분위기를 참고하는 용도**가 좋아 보여.

## 3순위: qrafthive

`minimal / professional / warm / pastel / startup`으로 분류돼 있어. Dashboard와 Mail 형태의 예시가 있어서, **실시간 대화나 메시지 기반 사용자 개입 UI**를 만들 때 참고하기 좋다. ([tweakcn][3])

### 잘 맞는 화면

- AI의 사전 질문
- 사용자의 선택 버튼
- 통화 중 추가 지시
- 온보딩
- 전화 요청 생성 화면

예를 들면:

> 상담사가 두 가지 시간을 제안했습니다.
>
> `[오전 10시]` `[오후 3시]` `[직접 입력]`

이런 질문 카드를 딱딱하지 않게 보여주기에 적합해.

다만 Pastel을 너무 많이 사용하면 병원·보험·공과금 업무가 가벼워 보일 수 있으니, **메인 컬러보다는 부드러운 보조 배경 정도로만 쓰는 게 나아.**
