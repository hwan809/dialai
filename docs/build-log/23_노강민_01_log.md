## 요약

이 폴더에서는 DialAI 해커톤 발표물을 준비하는 작업이 주로 수행되었다. 랜딩 페이지 방향 탐색과 계획 초안이 작성되었고, 이후 작업의 중심은 **10장짜리 한국어 HTML 슬라이드 덱**으로 이동했다.

현재까지 슬라이드 덱의 근거 자료, 디자인 계약, 10장 콘텐츠 구조, 전용 SVG 워드마크, 키보드·접근성 인터랙션 시제품, 생성 프롬프트 및 입력 묶음이 만들어졌다. 다만 Open Design Cloud 작업 연결이 끊겨 실제 덱 생성은 시작되지 않았으며, 최종 오프라인 HTML과 공유 링크도 아직 없다.

## 프로젝트별 진행 상태

### 1. DialAI 랜딩 페이지

상태: **기획 단계 / 구현되지 않음**

수행 내용:

- `Call Assistance → Call Delegation` 메시지와 한국어 중심의 랜딩 페이지 방향을 정리함.
- Warm Human + New Typography 기반의 디자인 방향, 금지할 AI 클리셰, 접근성·반응형 검증 범위를 정의함.
- 랜딩 페이지 작업 초안과 계획 파일을 작성함.

주요 기록:

- `.omo/drafts/dialai-landing-page.md`
- `.omo/plans/dialai-landing-page.md`
- `.playwright-mcp/dialai-notion-response.json`
- `.playwright-mcp/dialai-notion-response-161.json`

남은 일:

- 계획 파일의 실제 작업 항목 구체화
- Open Design 생성
- Next.js 랜딩 페이지 구현
- 빌드·접근성·반응형 브라우저 검증

### 2. DialAI HTML 슬라이드 덱

상태: **준비 자산 6개 작업 확인 완료, Cloud 생성 단계에서 중단**

목표:

- 1920×1080 기준의 한국어 10장 해커톤 피치 덱
- 공유 가능한 Open Design 링크와 네트워크 없이 열리는 단일 HTML 파일 동시 제공
- 검증된 사실과 계획된 MVP 동작을 명확히 구분

완료·확인된 작업:

1. DialAI 저장소 스냅샷과 제품 주장 원장 동결
2. 외부 통계·미술사 참고자료·폰트 라이선스 검증
3. 디자인 시스템, 타이포그래피, 워드마크, 모션 계약 확정
4. 정확히 10장인 콘텐츠·사실 상태 매트릭스 작성
5. 결정적 `dialai` SVG 워드마크 제작 및 160–1200px 렌더 검증
6. 키보드 탐색, URL 해시, 발표자 노트, 인용 패널, 포커스 복귀, reduced-motion을 포함한 인터랙션 시제품 제작 및 브라우저 검증

추가로 준비된 작업:

- Open Design 생성 프롬프트와 31개 입력 파일 묶음이 준비·검증됨.
- 현재 검증 영수증은 Task 8을 `verified`로 기록하지만, 실행 원장의 마지막 Task 8 이벤트는 이전 `needs-fix` 상태이고 계획 체크박스도 아직 갱신되지 않았다. 따라서 이 로그에서는 **산출물 검증 완료 / 오케스트레이션 기록 미동기화**로 분류한다.

차단된 작업:

- Open Design Cloud 사전 점검은 기존 워크플로-실행 연결이 사라져 중단됨.
- 명시적인 워크플로 재시작 없이는 단일 생성 실행을 안전하게 이어갈 수 없는 상태로 기록되어 있음.

아직 수행되지 않은 작업:

- 실제 Open Design 생성 실행
- 생성 완료 대기와 Studio 열기
- 최종 `dialai-deck.html` 회수·저장
- 최종 HTML의 자동 접근성·개인정보·오프라인 검사
- 전체 슬라이드 시각 QA와 anti-slop 검수
- 수정 라운드, 공유 링크와 오프라인 파일 최종 전달
